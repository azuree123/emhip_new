Data migration

Brings guest records across from the previous system (InForm) as a CSV upload — demographics, referral details, pathway and status, case notes and DIALOG scores. Original dates are kept as they were, so a migrated guest keeps its real registration and activity history rather than today’s date.

  1. 1 Download the template — one row of example data under every column the importer understands.
  2. 2 Map your export onto it — match your columns to the template’s, one guest per row.
  3. 3 Validate (dry run) — every row is checked and nothing is written.
  4. 4 Review the report — fix any flagged rows in your file and validate again.
  5. 5 Import — the same file, this time written to the live database.

Import template

Lists every supported column with an example row: demographics, referral information, pathway and status, notes and DIALOG scores. dialog_scores holds 11 numbers from 1 to 7, separated by spaces or semicolons. Include your old system’s identifier in legacy_id and the import becomes repeatable — running it again updates the guest that reference created instead of adding a duplicate.
